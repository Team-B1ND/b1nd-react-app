# 이슈 작성 방법

b1nd-react-app 개선에 도움을 주셔서 감사합니다! 아래 단계를 따라주세요:

## 빠른 단계

1. [Issues](https://github.com/Team-B1ND/b1nd-react-app/issues)로 이동
2. **"New issue"** 클릭
3. 이슈 타입 선택: **Bug Report** 또는 **Documentation**
4. 템플릿 작성
5. 제출!

## 이슈 작성 전

- [기존 이슈](https://github.com/Team-B1ND/b1nd-react-app/issues) 먼저 확인
- 기능 요청은 [토론](https://github.com/Team-B1ND/b1nd-react-app/discussions) 사용

## 팁

- **명확하고 간결하게**: 문제를 단순명확하게 설명
- **재현 방법 제공**: 어떻게 하면 같은 문제가 생기나요?
- **환경 정보 포함**: Node 버전, OS, 패키지 매니저
- **맥락 추가**: 스크린샷, 로그, 에러 메시지가 도움됨!

## 이슈 템플릿

다음 템플릿을 제공합니다:
- 🐛 **Bug Report**: 버그 및 이슈 보고
- 📚 **Documentation**: 문서 문제

템플릿을 작성해주시면 도와드리겠습니다! 감사합니다! 🙏
